# 04 · 四大运行制度

制度不是姿态，是给"每个新生命"预装的**固定动作**。四个制度各管一件事：报告管"干了什么"，纪要管"得出了什么"，交接管"跨天续做"，体检管"只增不减"。

## 1. 操作报告制度（动作流水账）

**触发**：凡是改动了文件、生成了文件、跑了下载或安装——每次都要。

**三件套**（缺一不算交付）：

1. 落一份 txt 到 `_ai_shared/reports/<日期>_<时间>_<主题>.txt`
2. 对话末尾给摘要卡片：干了什么 + 改动文件与大小 + 报错 + 要用户做什么
3. 卡片下跟一行**真实完整路径**（占位符等于没给地址）

**关键条款**：

- **弹窗与报错必须逐条列出**，哪怕自己已经处理掉——不报等于瞒。判定口径要宽：任何用户屏幕上的对话框、任何工具调用失败/超时/被拦截、任何互相矛盾的现象、任何"自己点掉"的异常
- 大小和占用给具体数字，不说"一些""不大"
- 纯问答、没动任何文件 → 不用卡片也不用 txt

## 2. 会议纪要制度（结论沉淀）

**触发**：调查 / 评审 / 方案对比类对话**收尾时**——哪怕全程没改任何文件。纯闲聊不写，宁可漏一份不可滥十份。

**与操作报告的分工**：报告记"干了什么"（流水账），纪要记"**得出了什么**"（结论、判据、待办）。一场重要讨论不落纪要，会话关闭后这段成果就物理上不存在了。

**格式**（模板见 [templates/meeting-minutes-system.md](../templates/meeting-minutes-system.md)）：

```markdown
# 会议纪要：<主题>
- 时间 / 参会：
- 一句话结论：
- 关键事实与判据：（带来源/路径/数字，可被反驳的那种，不写感想）
- 决议与待办：（谁、做什么、截止）
- 遗留疑问：（下次会话带入）
```

**规矩**：

- 结论必须写成"可被反驳的判据"，不写心得体会
- 引用别家 AI 的工作注明来源；执行者未署名的标"待认领"，**不替别家认领**
- 同日补充原地追加并标注版本；跨日或重大修订另立新文件
- 多 AI 场景：**接手任务先查最近一份纪要**，收尾写纪要——双向都写进触发表

## 3. HANDOFF 交接制度（跨天续做）

任务跨天或换工具时，先写/更新工作区根目录的 `HANDOFF.md`：目标、当前状态、关键决策、已完成、下一步。新会话开场先读它。

和纪要的分工：**HANDOFF = 单个任务的交接班记录；纪要 = 一场讨论的知识沉淀。** 两者并行，触发行都要在 L1 触发表里。

## 4. 记忆体检制度（只增不减）

记忆体系天然膨胀：L1 涨、纪要堆、条目过时。靠制度不靠自觉：

**每周固定时间或大变更后，任意一个 AI 执行四项检查，结果落一份操作报告：**

1. **L1 字符数** vs 注入窗口：超预警线（如 3600/3900）必须先瘦身（旧条目挪 L2）再允许加新
2. **过期条目**：扫 L1 和身份文件里带日期的时效性陈述（"xx 实测 / 当前 / 现配"字样），过期的当场更新或删
3. **纪要归档**：纪要目录超 30 份 → 最旧的移入 L3 归档
4. **操作报告永不清理**（流水账全保留）

有常驻自动化（定时任务/值守 AI）的，可以把体检交给它跑；没有的，每周固定时间对任意一个 AI 说一句"记忆体检"即可。
